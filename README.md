# Frontend Mentor - QR code Component

This is my first clean , interactive solution to the [QR code component challenge on Frontend Mentor](https://www.frontendmentor.io)

## 🚀Project Goal 
The goal of this beginner project challenge is to build out a static QR code preview card using semantic HTML5 markup and custom CSS properties to match the provided designer mockups exactly.

## 🛠️Built with
- ** semantic HTML5** - For the card layout  frameworks bones
- **Custom CSS Profile** - For Flexbox screen centering,rounded corners, and dropping a shadows
-**Google Fonts Engine** - used it for loading the offical typography styles
